A classe Veiculo representa um carro, com placa, motorista e combustível (privados, protegidos por encapsulamento).

Use adicionarCombustivel(litros) para abastecer e gastarCombustivel(litros) para rodar. Ambos bloqueiam valores inválidos, e não é possível deixar o tanque negativo.
